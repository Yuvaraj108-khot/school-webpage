First-Time Password Setup Instructions

A unique temporary password was created internally in Neon Auth and is intentionally never shown or saved. Share the login ID and setup steps below so the user sets their own password securely via Email OTP.

Steps for User / Parent:
  1. Open the Password Setup / Reset page (reset_password.html).
  2. Enter Login ID - to request a verification code.
  3. Check the registered email inbox for the 6-digit Neon Auth OTP code.
  4. Verify the OTP and set a personal password (minimum 8 characters).
  5. Sign in on the login portal using the Login ID and new password.
